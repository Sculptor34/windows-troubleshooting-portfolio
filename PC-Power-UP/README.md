# PC no power when press power button

# Overview
This project demonstrates the how to solve PC power issue.

## Problem
The motherboard no respond to PSU.

# Diagnosis
- Change the Power cable.
- Adjust all the peripherals cable
- Issue persists

# Solution
Steps performed:
1. Change the CMOS battery
2. Rub the RAM using eraser
3. Motherboard give respond to the PSU

# Commands Used
1. N/A

# Result
The PC able to power up
