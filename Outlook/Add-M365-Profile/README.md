# How to add M365 profile in outlook

# Overview
This project demonstrates the how to add M365 profile.

# Solution
Method 1:
1. Win+R: outlook.exe /profiles
2. Click Options
3. Add new profile

Method 2:
1. Open Control Panel
2. Click Mail (Microsoft outlook)
3. Select 'Choose profiles'
4. Add the new profile

# Result
The M365 profile add successfully in outlook
