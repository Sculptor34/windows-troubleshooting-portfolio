# The Internet page fail to load 

# Overview
This project demonstrates the how to solve internet connection stop working

## Problem
The internet fail to load page

# Diagnosis
- The Proxy server block network access

# Solution
Steps performed:
1. Open Internet Options
2. Click on 'LAN Setting'
3. Untick 'Automatically detect settings' & 'Proxy Server'

# Commands Used
1. N/A

# Result
The Internet accessible
