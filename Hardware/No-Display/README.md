# Laptop no display

# Overview
This project demonstrates the how to solve no display.

## Problem
The laptop no respond after force poweroff.

# Diagnosis
- The laptop unable to boot up.

# Solution
Steps performed:
1. Force power on the laptop (Method 1)
2. Swap the charger to make sure not charger/battery issue (Method 2)
3. Press Windows + ctrl + shift + B simultaneously to reset graphics driver (Method 3)

1. N/A

# Result
The Laptop able to power up
